## 1. Вход в систему

Откройте браузер и перейдите по адресу:

```text
https://www.nomadsarea.com/admin/
```

Введите логин и пароль от административной панели.

Если пароль утерян или вход не работает, обратитесь к разработчику или администратору проекта.

## 3. Настройки сайта

Раздел: **Настройки сайта → Настройки сайта**

Здесь хранится общая информация о компании, которая отображается на сайте.

> **Важно:** настройки сайта должны существовать в одном экземпляре. Не создавайте новую запись, если уже есть существующая. Редактируйте текущую запись.

### Контакты

| Поле | Что указывать |
|------|---------------|
| **Телефон** | Основной номер компании |
| **WhatsApp** | Номер для связи через WhatsApp |
| **Email** | Основная почта компании |

### Социальные сети

Заполните ссылки на социальные сети, если они используются:

- Instagram
- Facebook
- YouTube
- TikTok
- TripAdvisor или другой внешний сервис

Если какой-то соцсети нет, поле можно оставить пустым.

### О компании

| Поле | Что указывать |
|------|---------------|
| **Текст «О нас»** | Краткое описание компании |
| **Видео о компании** | Ссылка на видео или путь к видео, если поле настроено через админку |
| **Лет опыта** | Цифра для статистики на сайте |
| **Количество туристов** | Цифра для блока статистики |
| **Количество маршрутов** | Количество маршрутов/направлений |
| **Политика конфиденциальности** | Текст или ссылка, если используется на сайте |

## 4. Туры

Раздел: **Туры → Туры**

### Создание нового тура

1. Откройте раздел **Туры**.
2. Нажмите **Добавить тур**.
3. Заполните основные поля.
4. Добавьте фото, программу по дням, даты или ценовые тиры.
5. Нажмите **Сохранить**.

---

### Основная информация

| Поле | Описание |
|------|----------|
| **Название тура** | Название, которое будет видно на сайте |
| **Тип тура** | Групповой или приватный |
| **Активен** | Если включено, тур отображается на сайте |
| **Страна** | Страна тура |
| **Город** | Основной город или точка тура |
| **Категории** | Можно выбрать несколько категорий |

> Если тур не должен пока отображаться на сайте, снимите галочку **Активен**.

---

### Параметры тура

| Поле | Описание |
|------|----------|
| **Сезон** | Круглый год, тёплый сезон, зима и т.д. |
| **Длительность** | Количество дней тура |
| **Сложность** | Уровень сложности тура |
| **Максимум людей** | Актуально для групповых туров |
| **Цена** | Базовая цена за человека |
| **Валюта** | USD, KGS или другая доступная валюта |

---

### Описание тура

Заполните текстовые поля:

| Поле | Описание |
|------|----------|
| **Описание** | Краткое и понятное описание тура |
| **Что включено** | Услуги, входящие в стоимость |
| **Что не включено** | Услуги, которые оплачиваются отдельно |

Рекомендуется писать коротко, ясно и без лишней технической информации.

---

### Фотографии тура

В блоке **Фото тура**:

1. Нажмите **Добавить ещё одно фото**.
2. Загрузите изображение.
3. При необходимости заполните alt-текст.
4. Укажите порядок отображения.

Рекомендация по фото: горизонтальные изображения хорошего качества, желательно **1920×1080**.

> Первое фото обычно используется как обложка тура в каталоге.

---

### Программа по дням

В блоке **Маршрут по дням** добавьте описание каждого дня тура.

| Поле | Описание |
|------|----------|
| **Номер дня** | 1, 2, 3 и далее |
| **Заголовок** | Краткое название дня |
| **Описание** | Подробная программа дня |
| **Высота** | Например: 3500 м |
| **Пешая дистанция** | Например: 8 км |
| **Дистанция на машине** | Например: 120 км |
| **Проживание** | Юрта, гостиница, кемпинг и т.д. |

---

### Даты заездов для групповых туров

Для группового тура в блоке **Даты заезда** укажите доступные даты.

| Поле | Описание |
|------|----------|
| **Дата начала** | Дата старта тура |
| **Дата окончания** | Дата завершения тура |
| **Доступные места** | Количество свободных мест |

> Для приватных туров даты заездов обычно не нужны: клиент сам указывает желаемые даты при бронировании.

---

### Ценовые тиры для приватных туров

Для приватных туров можно указать цену в зависимости от количества людей.

| Поле | Описание |
|------|----------|
| **Минимум людей** | Например: 1 |
| **Максимум людей** | Например: 3. Если пусто - значит «и более» |
| **Цена за человека** | Цена для указанного диапазона |

Пример:

```text
1–2 человека  →  600 USD за человека
3–5 человек   →  450 USD за человека
6+ человек    →  350 USD за человека
```

> Диапазоны не должны пересекаться. Если они пересекаются, система покажет ошибку.

---

### Точки маршрута на карте

В блоке **Точки маршрута** можно добавить координаты для отображения маршрута на карте.

1. Откройте Google Maps.
2. Найдите нужную точку.
3. Скопируйте широту и долготу.
4. Укажите название точки в админке.
5. Сохраните тур.

---

### Сохранение тура

После заполнения нажмите **Сохранить**.

Тур появится на сайте, если:

- стоит галочка **Активен**;
- заполнены основные обязательные поля;
- добавлены корректные данные страны/города;
- тур доступен через активную категорию или прямую страницу.

## 7. Бронирования

Раздел: **Бронирования → Бронирования**

Здесь отображаются заявки клиентов на туры.

### Статусы бронирований

| Статус | Значение |
|--------|----------|
| **Ожидает** | Новая заявка, ожидает обработки |
| **Подтверждён** | Бронирование подтверждено, места зарезервированы |
| **Отменён** | Бронирование отменено |
| **Отклонён** | Заявка отклонена, например из-за отсутствия мест |

### Как подтвердить бронирование

1. Откройте раздел **Бронирования**.
2. Найдите нужную заявку.
3. Поставьте галочку рядом с заявкой.
4. В меню **Действие** выберите **Подтвердить и зарезервировать места**.
5. Нажмите **Выполнить**.

После подтверждения статус изменится на **Подтверждён**, а доступные места спишутся автоматически.

---

### Массовые действия

Можно обработать сразу несколько бронирований:

1. Отметьте нужные заявки галочками.
2. В меню **Действие** выберите нужное действие:
   - **Подтвердить и зарезервировать места**;
   - **Отменить выбранные брони**.
3. Нажмите **Выполнить**.

---

### Основные поля бронирования

| Поле | Описание |
|------|----------|
| **Клиент** | Имя и контакт клиента |
| **Тур** | Название выбранного тура |
| **Дата тура** | Дата группового тура |
| **Желаемые даты** | Даты, указанные клиентом для приватного тура |
| **Количество людей** | Взрослые + дети |
| **Цена за человека** | Рассчитывается системой |
| **Итоговая цена** | Полная стоимость бронирования |
| **Статус** | Текущий статус заявки |

## 8. Контактные заявки

Раздел: **Контакты → Контактные заявки**

Здесь находятся обращения с контактной формы сайта.

### Как обработать заявку

1. Откройте заявку.
2. Посмотрите имя, контакт, тему и сообщение.
3. Свяжитесь с клиентом удобным способом.
4. После ответа измените статус на **Отвечено**.
5. Сохраните изменения.

### Статусы

| Статус | Значение |
|--------|----------|
| **Ожидает ответа** | Новая заявка |
| **Отвечено** | Менеджер уже связался с клиентом |

## 9. Квиз и лиды

Раздел: **Квиз → Заявки с квиза**

Здесь отображаются лиды от пользователей, которые прошли квиз на сайте.

### Как обработать лид

1. Откройте лид.
2. Посмотрите блок **Ответы пользователя**.
3. Определите интересы клиента: направление, формат тура, бюджет, даты, количество людей.
4. Свяжитесь с клиентом по указанному контакту.
5. После обработки измените статус на **Обработан**.

---

### Настройка вопросов квиза

Раздел: **Квиз → Вопросы квиза**

Можно:

- добавить новый вопрос;
- изменить текст вопроса;
- изменить варианты ответов;
- изменить порядок вопросов;
- скрыть вопрос через поле **Активен**.

> Если пользователь начинает квиз повторно, его прогресс сбрасывается автоматически.

## 10. Отзывы

Собственной базы отзывов в системе нет. Отзывы отображаются через внешние виджеты.

| Виджет | Тип | Как настроить |
|--------|-----|---------------|
| **Google Reviews** | Elfsight | Вставить App ID |
| **TripAdvisor** | Внешний виджет или Elfsight | Указать App ID или параметры виджета |

### Как подключить Google Reviews через Elfsight

1. Перейдите на сайт [elfsight.com](https://elfsight.com).
2. Создайте виджет **Google Reviews**.
3. Скопируйте **App ID**.
4. В админке откройте: **Настройки сайта → Виджеты отзывов**.
5. Вставьте App ID в поле **Elfsight Google Reviews App ID**.
6. Включите переключатель **Виджеты отзывов включены**.

### Как подключить TripAdvisor

1. Подготовьте виджет через используемый сервис.
2. Скопируйте App ID или параметры, которые нужны фронтенду.
3. Вставьте их в соответствующее поле в настройках сайта.
4. Сохраните изменения.

### Как включить или выключить отзывы

Откройте **Настройки сайта → Виджеты отзывов** и измените переключатель **Виджеты отзывов включены**.

## 11. Достопримечательности

Раздел: **Достопримечательности → Достопримечательности**

Достопримечательности показываются на страницах городов и могут быть связаны с турами.

### Как добавить достопримечательность

1. Выберите **Город**.
2. Введите **Название**.
3. Заполните **Описание**.
4. Загрузите главное изображение, если поле доступно.
5. В блоке **Галерея** добавьте дополнительные фото.
6. В поле **Связанные туры** выберите туры, где посещается это место.
7. Включите **Активен**, если место должно отображаться на сайте.
8. Нажмите **Сохранить**.

> В одном городе не должно быть двух достопримечательностей с одинаковым названием.

## 15. Частые вопросы

### Тур создан, но не отображается на сайте

Проверьте:

- стоит ли галочка **Активен**;
- выбраны ли страна, город и категория;
- заполнены ли обязательные поля;
- активна ли категория тура.

---

### Клиент не может забронировать тур, пишет «нет мест»

Проверьте:

1. Откройте нужный тур.
2. Найдите блок **Даты заезда**.
3. Проверьте поле **Доступные места**.
4. Если мест нет, добавьте места или предложите клиенту другую дату.

---

### Бронирование не подтверждается

Проверьте:

- статус бронирования;
- выбранный тур;
- дату тура;
- доступные места;
- количество людей.

Онлайн-платежей сейчас нет. Оплату менеджер обрабатывает вручную.

---

### Не приходят уведомления в Telegram

Сообщите разработчику. Нужно проверить:

- токен Telegram-бота;
- ID чата;
- работу Celery;
- настройки сервера.

---

### Как изменить цену тура

1. Откройте раздел **Туры**.
2. Найдите нужный тур.
3. Измените поле **Цена**.
4. Нажмите **Сохранить**.

> Изменение цены не влияет на уже созданные бронирования.

---

### Клиент хочет отменить бронирование

1. Откройте раздел **Бронирования**.
2. Выберите нужную бронь.
3. Используйте действие **Отменить выбранные брони**.

Если клиент уже оплатил тур вручную, возврат обрабатывается менеджером по правилам компании.

---

### Не работает виджет отзывов

Проверьте:

1. Включён ли переключатель **Виджеты отзывов включены**.
2. Правильно ли указан App ID.
3. Не закончился ли тариф или доступ к внешнему сервису.

---
